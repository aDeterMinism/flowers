# 月光花园

一个为七夕准备的、隐私优先的浏览器摘花应用。访客可以浏览每一朵独立的花，摘走后库存即时减少；经明确同意后，浏览器信息和联系方式会在前端完成混合加密再上传。

## 运行

需要 Node.js 18 或更高版本，不需要安装依赖。

```bash
ADMIN_PASSWORD='换成你的强口令' node server.js
```

如果系统有 npm，也可以运行 `npm start`。

打开：

- 花园：`http://127.0.0.1:3000/`
- 管理：`http://127.0.0.1:3000/admin`

没有设置 `ADMIN_PASSWORD` 时，开发口令是 `garden`。

## 图片与交互

- 项目自带向日葵、康乃馨、玫瑰和水仙四组 WebP 默认图。每朵花都有独立的 `image` 与 `preview` 配置，同品种初始会共用默认图。
- 在管理端“花朵”页可以为任意一朵上传 JPG、PNG 或 WebP。浏览器会先缩小并转为 WebP，再同时上传主图和 96×96 小预览。
- 输入模式由一个全局状态管理，以最近一次真实的指针输入为准。鼠标模式下，指向 Dock 会立即更新文字，停留 130 ms 后才加载主图，点击直接进入摘花流程；触摸或手写笔模式下，先选花，再点击摘花按钮。
- 移动布局的 Dock 不显示罗盘，花朵列表以首尾相接的循环带滚动，离 Dock 几何中心最近的花始终是当前选中项。
- 小预览在空闲时低优先级预载；开启节省流量或 2G 网络时不批量预载。图片资源使用长期不变缓存。

## 首次设置

1. 登录管理端，进入“隐私与密钥”。
2. 点击“生成新密钥对并下载私钥”。私钥 JSON 只会下载到本机，不上传。
3. 点击右上角“保存配置”，让公钥保存到服务器。
4. 如需自动回信，在“回信”页填入 SMTP 参数，并允许访客选择明文上传邮箱。

访客数据使用 AES-256-GCM 加密；一次性 AES 密钥再由 RSA-OAEP 3072 位公钥封装。管理端解密时需要本地选择私钥文件，私钥仍不会上传。

## 数据与部署提示

- 数据保存在运行后生成的 `data/db.json`，请纳入服务器备份，但不要提交到 Git。
- 应用不接受任何访客附件或二进制上传。只有已登录管理员可上传花朵图片，服务端只接受管理页转换后、合计不超过 2 MiB 的 WebP 主图和小预览。
- 访客字段限制：留言 2,000 字符、邮箱 254、QQ 12、微信 64、电话 30、抖音与小红书各 80、飞书 100；完整明文载荷还受 16 KiB 前端上限与 32 KiB 密文信封服务端上限保护。
- SMTP 强制使用 TLS 直连（通常为 465），不会通过普通 TCP 发送认证信息。生产环境应放在 HTTPS 反向代理后。
- 每次成功写入 `data/db.json` 前都会保留上一版本为 `data/db.json.bak`。如果数据库 JSON 损坏或结构无效，服务会停止启动而不是回退为空数据库；请先检查文件或从备份恢复。
- **安全 TODO：**“导出全部”接口受管理员会话保护。当前导出文件包含 SMTP 密码、访客明确授权保存的明文字段以及全部密文记录。后续有计划将 SMTP 密码迁移到环境变量，并拆分数据管理，进一步降低未知的风险。
- 正式部署请务必设置强 `ADMIN_PASSWORD`、HTTPS、访问日志与定期备份。
